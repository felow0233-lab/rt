# Screen Translator RU

Real-time English-to-Russian screen translator for Android visual novels (polling every 500ms, translating only when text blocks or positions change).

## Setup in GitHub
1. Upload the contents of this archive into your repository (make sure `.github/workflows/build.yml` is inside `.github/workflows/`).
2. In **Settings → Actions → General**, set **Workflow permissions** to **Read and write permissions**.
3. Push to `main` or run the workflow manually under **Actions**.
4. Download `app-debug.apk` from **Releases** (`latest-apk`).
